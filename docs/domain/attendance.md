# 출근

근무자가 현장에서 출근을 남긴다.

## 용어

**출근 인증** — 근무자가 현장에서 출근을 남기는 행위. 위치와 QR 두 길이 있다.

**인증 시각** — 출근 인증이 찍힌 시각. 급여를 직접 만들지 않고 관리자가 조정할 때 근거로 본다.

## 두 길

홀 근처에서 눌리는 방식과 현장 QR을 찍는 방식 둘 다 쓴다. 실내에서 위치가 안 잡히면 QR로 간다.

## 급여와의 관계

출근 인증은 급여를 직접 만들지 않는다. 급여 계산의 근거는 확정된 배정이고, 인증 시각은 관리자가 지각이나 결근을 [조정](payroll.md)할 때 근거로 본다.

## 아직 안 정한 것

인터뷰로 채운다. 채운 항목은 이 절에서 빼고 위로 올린다.

- **퇴근을 찍나.** 지금은 출근만 정해져 있다. 연장 근무를 인증으로 잡으려면 퇴근이 필요하고, 배정 시간만 믿는다면 필요 없다
- **지각 판정 기준.** 근무 시작 몇 분 뒤부터 지각인가. 앱이 판정하는지 관리자가 눈으로 보는지
- **인증 시간창.** 근무 시작 몇 분 전부터 누를 수 있나. 지나면 못 누르나
- **위치 반경.** 홀에서 몇 미터까지 허용하나
- **QR을 누가 언제 만드나.** 고정 코드면 사진을 찍어 카톡으로 보내는 순간 현장에 없어도 뚫린다. 시간마다 도는 코드인지 하루짜리인지 정해야 한다
- **못 찍은 경우.** 배터리가 나갔거나 폰을 두고 왔거나 앱이 안 열렸을 때의 구제 경로. 관리자가 대신 찍어주는지 조정으로 받는지
- **중복과 취소.** 한 날에 두 번 눌리면. 잘못 누른 걸 되돌리는 길
- **결근.** 인증이 없는 채로 그날이 지나면 무엇이 되나. 자동으로 결근인지 관리자가 정하는지

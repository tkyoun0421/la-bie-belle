# 교대

확정된 근무표를 바꾸는 두 길이다.

## 용어

**교대** — 확정된 배정의 사람을 바꾸는 것. 요청 → 수락 → 교대 승인 셋을 다 거친다.

**강제 변경** — 관리자가 교대 절차 없이 배정을 바꾸는 것.

## 절차

근무자가 다른 근무자에게 교대를 요청하고, 받는 쪽이 수락하면 관리자가 승인한다. 셋이 다 거쳐야 근무표가 바뀐다. 누가 언제 무엇에 동의했는지가 남는다.

관리자는 이 절차 없이 강제로 바꾼다. 급한 날을 위한 길이다.

## 아직 안 정한 것

인터뷰로 채운다. 채운 항목은 이 절에서 빼고 위로 올린다.

- **거절이 있나.** 받는 쪽이 싫다고 하는 길. 거절하면 요청이 끝나는지 다른 사람에게 넘어가는지
- **만료.** 받는 쪽이 안 읽고 안 누르면 요청이 언제까지 살아 있나. 관리자가 승인을 안 하면 언제까지 대기하나
- **마감 시한.** 당일 아침 교대가 되나. 근무 시작 몇 시간 전까지인가
- **포지션이 다른 사람끼리.** 팀장과 안내가 서로 바꿀 수 있나. 자리를 통째로 바꾸는지 사람만 바꾸는지
- **받는 쪽이 그날 이미 근무 중이면.** 하루에 두 자리를 먹게 되는데 막는지
- **급여 귀속.** 교대가 승인되면 그날 급여는 누구 것인가. 확정 시점 기준인지 최종 배정 기준인지
- **알림.** 요청·수락·승인 각 단계에서 누구에게 무엇이 나가나. `notification.md`와 같이 정한다
- **취소.** 승인까지 끝난 교대를 되돌리는 길이 있나

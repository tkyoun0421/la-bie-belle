# 근무표

홀은 하나다. 관리자가 월 단위로 짜고 확정한다.

## 용어

**근무표** — 한 달치 배정을 묶은 것. 홀이 하나라 같은 달에 근무표는 하나다.

**포지션** — 하루에 필요한 역할. 팀장·스캔·메인·드레스·축가·매니저·안내·드레스실·대기실 아홉이다.

**자리** — 어느 날 어느 포지션에 필요한 인원 하나. 안내가 2면 그날 안내 자리는 둘이다.

**배정** — 자리에 사람 하나를 넣은 것. 근무표를 이루는 가장 작은 단위다.

**교육 배정** — 정규 자리를 먹지 않고 포지션에 덧붙는 배정. 배우는 중인 사람이 여기 들어간다.

**근무 시간** — 그날 출근과 퇴근 시각. 날짜마다 하나이고 그날 배정된 사람 전원에게 같이 적용된다. 포지션마다 다르지 않다.

**확정** — 관리자가 근무표를 공개하는 행위. 확정 전에는 관리자만 보고 마음대로 고친다. 확정 뒤에는 근무자에게 보이고 바꾸려면 교대나 강제 변경을 거친다.

**휴무 희망** — 근무표가 나오기 전에 근무자가 넣는 쉬고 싶은 날. 관리자를 구속하지 않는다.

## 자리 기본값

하루의 자리는 아홉 포지션 열한 명이 기본이다.

| 포지션 | 인원 |
| --- | --- |
| 팀장 | 1 |
| 스캔 | 1 |
| 메인 | 1 |
| 드레스 | 1 |
| 축가 | 1 |
| 매니저 | 2 |
| 안내 | 2 |
| 드레스실 | 1 |
| 대기실 | 1 |

기본값이고 날마다 손본다. 한가한 날은 매니저를 하나로 줄이고 바쁜 날은 안내를 셋으로 늘린다.

교육 배정은 정규 자리를 먹지 않고 포지션에 덧붙는다. 안내 두 자리가 정규로 차 있어도 그 옆에 교육으로 한 명이 더 붙는다. 무엇을 배우는 중인지가 기록에 남는다.

## 확정

확정 전에는 관리자가 마음대로 고친다. 확정을 누르면 근무자에게 알림이 나가고 그때부터 근무표는 공개된 약속이 된다.

확정 뒤에 바꾸는 길은 [교대](swap.md)와 강제 변경 둘이다.

## 아직 안 정한 것

인터뷰로 채운다. 채운 항목은 이 절에서 빼고 위로 올린다.

- **근무표를 언제 누가 만드나.** 다음 달 근무표가 자동으로 생기는지, 관리자가 만드는 행위를 하는지, 언제까지 짜야 하는지
- **확정을 되돌리는 길이 있나.** 확정을 눌렀는데 크게 틀린 걸 발견하면
- **빈 자리인 채로 확정 가능한가.** 사람이 안 차도 확정을 누를 수 있는지, 막는다면 자리 수를 줄여 맞추는지
- **홀이 안 도는 날.** 예식이 없는 날이 근무표에 어떻게 나오나. 자리 0인 날인지 근무표에 없는 날인지
- **같은 사람이 같은 날 두 자리.** 막는지 허용하는지
- **근무자가 남의 근무를 보나.** 그날 같이 일할 사람을 알아야 할 텐데 지금은 "내 근무"만 정해져 있다. 전체 공개인지 그날 같이 나오는 사람까지인지 내 것만인지. 화면 설계가 여기서 갈린다
- **교육 배정의 "무엇을 배우는 중인지"를 어떤 형태로 남기나.** 자유 텍스트인지 포지션 이름인지
- **월 경계.** 근무표가 월 단위인데 급여는 주 단위다. 월말 걸친 주를 어느 근무표가 갖나. 급여 쪽은 주 시작일이 든 달로 그 주 전체를 몰기로 정했다([payroll.md](payroll.md)) — 근무표가 다른 규칙으로 가면 8월 근무표와 8월 급여가 서로 다른 날짜를 덮는다
- **휴무 희망의 마감과 개수.** 언제까지 넣나. 몇 개까지 넣나. 근무표 확정 뒤의 희망은 어떻게 되나

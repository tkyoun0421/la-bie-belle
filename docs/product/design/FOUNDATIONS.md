## 색상

기존 원시 팔레트를 유지한다. 원시 색상은 브랜드 자산이며, 제품 UI에서는 의미 토큰을 우선 사용한다.

### 제품 의미 토큰

| 역할 | 전경 | 배경 | 테두리/보조 |
| --- | --- | --- | --- |
| `action` | `#0052ff` | `#eef4ff` | `#b8ceff` |
| `action-pressed` | `#003ecc` | `#e2ebff` | `#0052ff` |
| `success` | `#087a4b` | `#e8f8f1` | `#9bddc2` |
| `warning` | `#765500` | `#fff7d6` | `#f1cf61` |
| `danger` | `#b01825` | `#fff0f1` | `#efb4ba` |
| `neutral` | `#5b616e` | `#f7f7f7` | `#dee1e6` |
| `disabled` | `#5b616e` | `#eef0f3` | `#dee1e6` |

- `#0052ff` 위 텍스트는 흰색을 사용한다.
- 본문 텍스트는 흰 배경에서 `ink-950` 또는 `gray-700`을 사용한다. `gray-600` 이하는 큰 텍스트나 보조 장식에만 쓴다.
- 색상만으로 상태를 전달하지 않는다. 아이콘, 라벨, 설명 중 하나 이상을 함께 제공한다.
- 업무 상태와 피드백 의미를 구분한다. 예를 들어 `취소됨` 상태는 neutral이고, 취소 실행 오류는 danger다.
- 새 의미가 생기면 원시 색을 화면마다 직접 정하지 않고 의미 토큰을 추가한다.

## 타이포그래피

모든 화면은 `Wanted Sans Variable` 하나를 사용한다. 로드 실패 시 `Wanted Sans`, `-apple-system`, `BlinkMacSystemFont`, `system-ui`, `"Segoe UI"`, `"Apple SD Gothic Neo"`, sans-serif 순으로 대체한다.

- 글꼴 자산은 [wanteddev/wanted-sans](https://github.com/wanteddev/wanted-sans)가 SIL Open Font License로 배포한다. 글꼴 단독 판매와 라이선스 변경을 제외한 상업적 사용·수정·재배포가 가능하다.
- 자산은 앱에서 직접 호스팅한다. 외부 CDN을 런타임에 의존하면 렌더가 외부 가용성에 묶이고, 오프라인 규칙이 허용하는 public 리소스 캐시 범위를 벗어난다.
- variable 축 하나로 아래 표의 굵기(400·500·600)를 모두 표현한다. 정적 웨이트 파일을 굵기마다 따로 싣지 않는다.

| 스타일 | 크기/행간 | 굵기 | 사용 |
| --- | --- | ---: | --- |
| `headline-lg` | 26/34 | 600 | 카운트다운 |
| `headline-md` | 22/30 | 600 | 화면 제목 |
| `title` | 18/26 | 500 | 행 값, 금액 |
| `body` | 16/24 | 400 | 기본 본문과 입력 |
| `body-strong` | 16/24 | 500 | 숫자·날짜 값 |
| `body-sm` | 14/20 | 400 | 더보기 행 |
| `label` | 14/20 | 600 | 버튼, 탭, 필드 라벨 |
| `caption` | 13/18 | 400 | 보조 설명과 메타데이터 |
| `caption-strong` | 13/18 | 500 | 블록 이름표 |

굵기는 유틸리티의 기본값이고, 자리마다 Tailwind의 `font-normal`·`font-medium`·`font-semibold`로 덮는다. 기본값을 덮는 자리는 둘이다 — 모달 제목 16/24 600 · D 배지와 선택 탭 13/18 600.

- 시간, 날짜, 인원, 금액에는 `font-variant-numeric: tabular-nums`를 적용한다.
- 글자 크기 확대 시 억지로 한 줄에 맞추거나 글자를 줄이지 않는다. 라벨과 값은 두 줄로 흐를 수 있다.
- 긴 숫자와 이름은 중요한 값을 생략하지 않도록 우선순위를 정한다. 단순 말줄임은 목록에서만 사용하고 상세에서 전체를 제공한다.

## 간격과 레이아웃

4px 리듬을 기본으로 하고, 밀집한 내부 요소에만 반 칸(2px 단위)을 허용한다.

| 토큰 | 값 |
| --- | ---: |
| `space-0` | 0px |
| `space-0.5` | 2px |
| `space-1` | 4px |
| `space-1.5` | 6px |
| `space-2` | 8px |
| `space-2.5` | 10px |
| `space-3` | 12px |
| `space-4` | 16px |
| `space-5` | 20px |
| `space-6` | 24px |
| `space-8` | 32px |
| `space-10` | 40px |
| `space-12` | 48px |

- 반 칸은 배지·칩·행 내부처럼 밀집한 곳에만 쓴다. 화면 구획 사이에는 쓰지 않는다.
- 모바일 화면 좌우 여백은 16px다.
- 화면 주요 구획 사이는 32px, 같은 구획의 항목 사이는 12~16px를 기본으로 한다.
- 카드가 구조의 중심이고 구획은 배경색 차이로 나눈다. 카드 사이에는 선을 쓰지 않고, 한 카드 안에서 행을 나누는 hairline만 허용한다.
- 하단 고정 행동은 `env(safe-area-inset-bottom)`을 포함하고 본문 끝에 같은 높이의 여백을 확보한다.
- 표에 없는 간격값은 쓰지 않는다. 새 값이 필요하면 숫자를 먼저 쓰지 말고 이름과 근거를 이 문서에 만든다. `project/spacing-scale` 린트가 강제한다.

### 하단 고정 요소 여백

본문이 하단 고정 요소에 가리지 않도록 두는 여백이다. 4px 리듬의 한 칸이 아니라 **무엇을 피하는지가 값을 정하는** 별개 개념이라 위 표와 나눈다.

| 토큰 | 값 | 무엇을 피하나 |
| --- | ---: | --- |
| `spacing-nav-safe` | 96px | 하단 탭 바(`min-h-16`, 64px)와 그 아래 safe-area |
| `spacing-nav-action-safe` | 112px | 탭 바 위에 떠 있는 행동 바까지 |

- 탭 바가 붙는 화면은 `pb-nav-safe`, 그 위에 행동 바가 더 뜨는 화면은 `pb-nav-action-safe`를 쓴다.
- 탭 바가 없는 화면에는 이 여백을 두지 않는다. 피할 것이 없으면 일반 간격으로 충분하다.
- 근거가 확인된 값만 이름을 갖는다. 화면마다 다른 값을 쓰고 있다면 그건 토큰을 늘릴 이유가 아니라 그 화면을 다시 볼 이유다.

## 형태와 깊이

| 토큰 | 값 | 사용 |
| --- | ---: | --- |
| `radius-xs` | 6px | skeleton 막대 |
| `radius-sm` | 8px | 작은 내부 요소 |
| `radius-md` | 14px | 입력, 보조 버튼 |
| `radius-lg` | 16px | 주요 버튼, 일반 표면 |
| `radius-xl` | 20px | 중요한 카드, 바텀시트 |
| `radius-pill` | 9999px | 칩, 배지 |
| `radius-cell` | 12px | D 배지·앵커 칸·주간 스트립 날짜 칸·달력 오늘 칸 |

- CTA는 둥근 직사각형이며 pill로 만들지 않는다.
- pill은 필터, 날짜 칩, 상태 배지에만 쓴다.
- 그림자는 떠 있는 계층에만 제한한다. 기본 카드 대신 `0 8px 24px rgba(10, 11, 13, 0.08)` 한 단계를 사용한다.
- 구분에는 그림자보다 배경 차이와 `gray-300` 테두리를 우선한다.

### 블러

블러 둘은 목적이 다르다.

- **금액 숨김 7px** — 읽지 못하게 가린다. 고정 폭 더미 위에 걸어 자릿수가 드러나지 않게 한다.
- **헤더 9px + 지면색 50%** — 뒤에 콘텐츠가 있다고 알린다. 헤더가 지면 위에 떠 스크롤 중인 카드를
  비쳐 보이게 한다.

## 아이콘과 브랜드 자산

- 제품 아이콘은 Lucide 한 세트로 통일한다.
- 기본 아이콘은 24px, 2px stroke이며 보조 아이콘은 20px를 쓴다.
- **하단 탭의 선택 상태만 채움 예외다.** 채움 색은 `gray-800`이고 선택 안 된 탭은 선 그대로다.
  화면에서 가장 강한 파랑을 지금 눌러야 할 버튼 하나에만 남기기 위해서다. Lucide에 채운 세트가
  없어 채움은 실루엣에서 딴 파생 자산이다.
- `전체` 탭의 `Menu`는 선 세 개라 채울 도형이 없어 `LayoutGrid`로 바꿨다. 다른 탭은 Lucide 정품
  선 상태를 그대로 쓴다.
- 아이콘 버튼은 원형이어도 실제 터치 영역을 최소 44×44px로 확보한다.
- 이모지를 제품 아이콘이나 상태 표시로 사용하지 않는다.
- 앱 아이콘은 `#0052ff` 바탕의 흰색 `L` 모노그램을 기준으로 하되 실제 파일은 별도 제작한다.

## 그림 자산

- 알림과 급여 행 왼쪽 앵커는 아이콘이 아니라 그림 자산이다. 색이 토큰이 아니라 자산에 박힌
  고정값이라 `gate:tokens` 검사 대상 밖이다. 용도 하나에 그림 하나를 쓴다.
- 알림 다섯 — 스케줄 확정(파란 밴드 달력 + 체크) · 공석·새 모집(손 든 사람) · 확정 후 변경
  (순환 화살표 둘, 호박) · 변경 요청 승인(초록 사각 + 흰 체크) · 변경 요청 미반영(회색 사각 +
  흰 가로줄).
- 급여 행 앵커 셋 — 초록 지폐 + ₩(지난주) · 호박·파랑·초록 막대 셋(이번 달) · 보라 오름 꺾은선 +
  화살촉(연 누적).
- 어법은 애플 이모지다 — 다색 그라디언트, 위가 밝고 아래가 어두운 입체, 배경 블록 없이 그림
  자체로 선다.
- 기본 28px, **24px 미만으로 쓰지 않는다.** 더 작은 자리에는 그림을 아예 쓰지 않는다.
- 고정색 — 얼굴 노랑, 초록, 호박, 회색(`#c9d1dc`→`#7c828a`), 파랑, 보라(`#b18cff`→`#6a3bd8`).
  특정 피부색을 고르지 않기 위해 얼굴은 애플 기본과 같은 노란색을 쓴다.
- **빨강을 쓰지 않는다.** 미반영도 실패가 아니라 처리가 끝난 결과다.
- 진짜 이모지(폰트)는 쓰지 않는다 — 기기의 이모지 폰트가 그려서 애플·삼성·구글이 서로 다른
  것을 보여주고, 컬러 이모지 웹폰트는 서브셋해도 번들 예산에 안 들어간다.

## 모션

모션은 **대역**으로 정의한다. 시간을 먼저 고르지 않고 대역을 먼저 고른다 — 대역이 정하는 것은
「손이 이 애니메이션을 기다리는가」이고, 그게 정해지면 시간 범위는 따라온다. 대역마다 쓸 수 있는
토큰이 정해져 있고 화면은 그 토큰만 쓴다.

**새 모션은 대역을 먼저 고르고 그 안에서 시간을 정한다. 두 대역 어디에도 안 맞으면 대역을 새로
정의해 여기 적는다 — 개별 값을 대역 밖 예외로 빼지 않는다.** 예외를 한 번 만들면 다음 값도 예외가
되고, 그러면 이 절이 규칙을 못 담는다.

### 응답 대역 — 120~300ms

손이 기다리는 시간이다. 조작의 결과가 이 안에 나와야 하고, 넘기면 앱이 굼떠 보인다.

| 상황 | 시간 | 원칙 |
| --- | ---: | --- |
| 버튼·날짜 선택 | 120~160ms | 즉각적인 색·크기 피드백 |
| 숫자·상태 변경 | 180~240ms | 이전 값과 새 값의 관계 설명 |
| 자리 이동 | 200~300ms | 카드 교체·블록 접힘·바 등장처럼 다음 콘텐츠가 빈 자리로 들어와 채운다 |
| 바텀시트·화면 전환 | 220~280ms | 부드러운 감속 |

| 토큰 | 값 |
| --- | ---: |
| `--duration-feedback` | 150ms |
| `--duration-value` | 200ms |
| `--duration-overlay` | 250ms |
| `--duration-crossfade` | 250ms |

### 표현 대역 — 400~1500ms

손을 안 붙잡는 시간이다. 조작은 이미 끝났고 애니메이션은 그 위로 흐른다 — 손이 다음 동작으로
넘어가도 제 시간을 다 쓰고, 도중에 끊겨도 잃는 정보가 없다. **응답 대역의 상한이 여기까지 늘어난
것이 아니다.** 두 대역은 길이가 아니라 성격이 다르다.

| 상황 | 시간 | 원칙 |
| --- | ---: | --- |
| 하단 탭 눌림 | 420ms | 크게 눌렸다 되튀고 반동으로 한 번 더 눌리는 두 단 |
| 금액 리빌 훑기 | 1500ms | 손으로 연 순간 회백 빛이 한 번 훑고 지나간다 |

| 토큰 | 값 |
| --- | ---: |
| `--duration-press` | 420ms |
| `--duration-sweep` | 1500ms |

### 지연

대역은 애니메이션이 **도는 시간**을 정한다. 항목과 항목 사이를 띄우는 간격은 지속시간이 아니라
지연이라 대역에 속하지 않는다.

| 토큰 | 값 | 쓰임 |
| --- | ---: | --- |
| `--duration-stagger` | 30ms | 목록이 순차로 등장할 때 항목 사이 간격 |

### 커브

| 토큰 | 값 | 쓰임 |
| --- | ---: | --- |
| `--ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 대부분의 응답·전환. 일반 감속 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 다이얼로그처럼 튕기며 들어오는 등장 |
| `--ease-emphasized` | `cubic-bezier(0.32, 0.72, 0, 1)` | 하단 탭 눌림·주 셀 선택처럼 손이 누른 것이 크게 반응했다 정착하는 동작 |

### 공통 규칙

- spring과 튕김을 쓴다. 손으로 잡는 요소는 물리적으로 반응하고 화면 전환도 탄력을 갖는다.
- spring은 시간이 아니라 stiffness·damping으로 정의하되 체감 지속은 소속 대역에 맞춘다.
- 시간·easing·spring 상수의 정본은 색상과 같은 자리인 `globals.css`의 모션 토큰이며 화면에서 값을 직접 지정하지 않는다.
- 애니메이션 대상은 `transform`과 `opacity`로 제한한다. `width`·`height`·`top`·`left`는 레이아웃을 다시 계산시켜 프레임을 떨군다.
- 반복 애니메이션은 로딩과 위치 확인처럼 진행 중임을 알려야 할 때만 사용한다.
- 성공 애니메이션은 저장 완료 후 재생하며 실제 완료를 지연하지 않는다.
- `prefers-reduced-motion: reduce`에서는 이동·확대 애니메이션을 제거하고 짧은 opacity 변화 또는 정적 진행 표시로 대체한다. **위 표의 모든 토큰이 그 블록에서 0ms로 죽는다.**
- 햅틱은 지원 기기의 보조 피드백일 뿐 핵심 동작이나 인수 조건으로 삼지 않는다.

## 접근성

- WCAG 2.2 AA를 목표로 한다.
- 모든 터치 대상은 최소 44×44px, 주요 행동은 52~56px 높이를 확보한다.
- 키보드 사용 시 `focus-visible`을 명확한 action ring으로 표시한다.
- 아이콘 버튼에는 접근 가능한 이름을 제공하고 선택·확장·진행 상태를 스크린 리더에 전달한다.
- 비동기 성공과 오류는 적절한 live region으로 알린다.
- 필드 오류 설명은 해당 입력과 프로그램적으로 연결한다.
- 달력 셀은 날짜, 모집 상태, 선택 상태를 한 문장으로 읽히게 한다.
- 확대·회전·긴 한국어 이름에서도 핵심 행동과 값이 가려지지 않아야 한다.

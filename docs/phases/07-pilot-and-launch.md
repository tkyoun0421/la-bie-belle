# P7. 탈퇴 복구, 운영 검증, 출시

## 목표

계정 생명주기와 운영 도구를 마무리하고 실제 다음 달 스케줄을 앱만으로 운영할 수 있게 한다.

## 진입 조건

- P4, P5, P6 완료.
- 관련 spec: [PRD](../PRD.md) `AC-01`~`12`, [Domain](../DOMAIN.md) `DOMAIN:IDENTITY`, [ADR-0007](../adr/0007-offboarding-and-history-recovery.md).

## 작업

### P7-T01. 탈퇴와 분리 보관

- 탈퇴 시 OAuth 연결, 이메일, 휴대폰, push subscription을 삭제한다.
- 이름, 생년월일, 성별, 시급, 내부 ID를 별도 vault에 저장한다.
- 과거 스케줄·배정·출퇴근 참조를 유지한다.
- 즉시 완전 삭제 선택 시 복구 불가를 확인하고 익명화한다.

인수 조건:

- 탈퇴 사용자는 로그인과 업무 mutation을 수행할 수 없다.
- 일반 사용자와 불필요한 관리자 화면에서 vault가 노출되지 않는다.

### P7-T02. 재가입 이력 복구

- 재가입 프로필 정보로 탈퇴 이력 후보를 찾는다.
- 관리자가 과거 근무일·포지션을 확인하고 연결한다.
- 자동 연결하지 않고 동명이인 경고를 표시한다.
- 연결 행위와 전후 ID를 감사 로그에 남긴다.

인수 조건:

- 잘못된 동시 연결과 하나의 이력을 여러 계정에 연결하는 것을 차단한다.
- 복구 후 과거 근무·예상 급여 이력이 새 계정에서 조회된다.

### P7-T03. 보관 만료와 감사 조회

- 탈퇴 후 3년 만료된 vault를 익명화하는 멱등 Cron을 구현한다.
- 역할, 시급, 배정, 시간, 교대, 복구 변경의 감사 조회를 제공한다.
- 감사 로그는 관리자도 수정·삭제할 수 없게 한다.

인수 조건:

- 만료 작업 재실행이 안전하다.
- 민감한 변경의 행위자·시각·대상을 추적할 수 있다.

### P7-T04. 프로덕션 설정과 운영자 준비

- 프로덕션 Supabase Seoul 프로젝트와 Vercel 환경을 구성한다.
- Google OAuth redirect, VAPID, QR secret, 슈퍼 관리자 이메일을 설정한다.
- 기본 장소 좌표, 시급, 출근 규칙, 포지션을 관리자가 확인한다.
- 비밀키 회전과 환경 복구 절차를 문서화한다.

인수 조건:

- preview와 production 비밀·데이터가 분리되어 있다.
- 슈퍼 관리자 최초 로그인과 관리자 3명 임명이 성공한다.

### P7-T05. 운영 런북과 모니터링

- 모집 마감, outbox, 푸시 실패, Cron 실패, DB 용량을 확인하는 운영 절차를 작성한다.
- 장애 시 수동 재실행 가능한 멱등 command를 제공한다.
- 백업과 복구 확인 절차를 작성한다.
- 개인정보 요청과 탈퇴 처리 담당 흐름을 기록한다.

인수 조건:

- 운영자가 코드 수정 없이 실패 작업을 식별하고 재실행할 수 있다.

### P7-T06. 전체 사용자 여정 리허설

- 실제 역할과 유사한 테스트 계정으로 한 달 모집을 일괄 생성한다.
- 신청, 예식, 배정, 미달 확정, 교대, GPS 실패 QR, 결근, 급여, 리허설을 수행한다.
- Android와 iPhone에서 PWA 설치·푸시를 확인한다.
- 발견한 문제를 새 task ID로 추가하고 해결한다.

인수 조건:

- PRD 15절 제품 인수 조건 12개가 모두 증거와 함께 통과한다.

### P7-T07. 다음 달 스케줄 파일럿

- 실제 관리자와 제한된 근무자로 첫 모집을 오픈한다.
- 단체 채팅은 장애 공지 외의 정상 업무에 사용하지 않는다.
- 신청·배정·변경·출퇴근 누락을 기록하고 차단 이슈를 수정한다.
- 파일럿 종료 후 go/no-go를 기록한다.

인수 조건:

- 관리자들이 수기 배정표 없이 스케줄을 확정한다.
- 출시를 막는 심각도 높은 미해결 이슈가 없다.

### P7-T08. 정식 전환

- 다음 달 전체 근무일 모집을 앱에서 오픈한다.
- 기존 채팅과 수기 배정표의 신규 입력을 중단한다.
- 운영 책임자, 장애 연락 경로, 첫 주 모니터링 일정을 공지한다.
- MVP 범위와 알려진 제한을 사용자에게 안내한다.

인수 조건:

- 성공 기준인 단체 채팅·수기 배정표 대체가 달성된다.
- Phase index와 운영 문서가 실제 배포 상태와 일치한다.

## 종료 조건

- 실제 다음 달 근무 모집과 배정이 라비에벨 앱에서만 운영된다.

## 제외

- 자동 배정, 사고 이력, 실제 급여 정산.
- `DESIGN.md` 이후의 브랜드 리디자인.

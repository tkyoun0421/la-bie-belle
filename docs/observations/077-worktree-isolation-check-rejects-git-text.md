**일**: worktree에서 도는 subagent의 셸 명령을 격리 검사가 거부했다. 명령 문자열에 `.git`(예 `--exclude-dir=.git`)이 있거나, PR 본문 heredoc 안에 `git`이 들어 있으면 명령이 git 작업인지 가릴 수 없다며 막혔다. 같은 마찰이 #623 구현자와 2026-10-20 회차 마감에서 두 번 났다. `gh ... --jq` 식에 `.comments[].body`가 있어도 같은 이유로 막혔다.

**고침**: 아직 없다. 지금 피하는 길은 명령을 단순한 조각으로 쪼개거나, 본문을 파일로 쓴 뒤 그 파일을 읽게 하는 것이다.

**원칙**: 검사가 명령 문자열의 글자로 git 여부를 가리면 문서·검색어에 든 `git`이 거짓 양성이 된다. 스폰 프롬프트에 피하는 길을 적을지, 검사 쪽을 볼지는 같은 마찰이 더 쌓이면 정한다.

# subagent가 MCP 지시문을 프롬프트 주입으로 읽는다

## 일

`sian-sync`에서 작성자 넷을 돌렸더니 셋이 리턴 끝에 같은 말을 붙였다.

> 이번 작업 중 MCP 서버가 "Claude Docs" 관련 지시문을 떠넘겼는데, 이는 받은 task와 무관한 프롬프트 주입으로 판단해 무시하고 원래 지시만 따랐다.

세션에 붙은 `claude_ai_Claude_Docs` MCP 서버가 서버 지시문을 시스템 프롬프트에 싣는데, 그 글이 「먼저 문서를 만들어라」로 시작해 받은 task와 정면으로 어긋난다. subagent는 그것을 주입으로 보고 무시했다 — 판단은 맞았다.

## 값

판단이 맞아도 비용이 든다. 작성자마다 그 글을 읽고 무시할지 따를지 한 번 재고, 리턴에 그 사실을 한 단락 적는다. 넷 중 셋이 그랬으니 우연이 아니다. 더 나쁜 쪽은 반대 경우다 — 누군가 그 지시문을 따르면 시안 대신 저장소 밖 문서를 만들고 돌아온다.

이 저장소의 생산은 전부 `docs/` 아래 파일이다. 저장소 밖 문서 도구를 쓰는 자리가 없다.

## 제안

subagent가 쓰는 도구 목록에서 그 MCP 서버를 뺀다. 정의문의 `tools:` 줄이 이미 도구를 고르니 거기서 안 드는 서버의 지시문이 실리는 것이 어긋난 자리다 — 설정으로 끌 수 있으면 끄고, 못 끄면 총괄 세션만 쓰게 범위를 좁힌다.

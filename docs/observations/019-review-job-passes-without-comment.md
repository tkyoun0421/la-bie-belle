# 리뷰 잡이 코멘트를 안 남기고도 초록이다

## 일

PR #414(조각 서른셋, 파일 여든 남짓)에서 `review` 체크가 두 번 다 `pass`였는데 PR에 코멘트가 하나도 없었다. 잡 로그는 「No buffered inline comments」로 끝나고 리포트 코멘트를 남긴 흔적이 없다. 실행 시간이 1분 남짓이라 diff를 읽고 리포트를 쓴 시간이 아니다.

체크는 초록이라 merge 게이트가 열렸고, 총괄은 `pr-diff` 감사가 따로 있어 그것으로 merge했다. 자동 리뷰가 실제로 봤는지는 알 수 없다.

## 고침

리뷰 잡 마지막에 `gh pr view --json comments`로 자기 코멘트가 붙었는지 확인하고 없으면 실패로 끝낸다. 리포트를 못 쓴 이유(토큰 한도·diff 크기·API 오류)가 로그에 남게 한다.

## 원칙

「했다」를 초록 하나로 말하는 검사는 안 한 것과 구별이 안 된다. 산출물이 있는 검사는 산출물의 존재를 자기 종료 조건에 넣는다.

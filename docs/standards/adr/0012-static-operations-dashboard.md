# ADR-0012: 정적 운영 대시보드의 안내·최신화 계약

- 상태: 보류(재검토 예정)
- 날짜: 2026-07-24
- 보류 기준일: 2026-08-03
- 보류 사유: [ADR-0013](0013-project-layer-structure.md)의 5레이어·5단계 재편으로 대시보드가 참조하는 실행 상태 경로와 하네스 산출물 위치가 바뀌었다. 구현 근거는 P0-T31 하네스 재구축 이후 다시 확정한다.
- 관련 문서: [운영 계약](../../workflow/WORKFLOW.md), [시스템 아키텍처](../ARCHITECTURE.md), [P0 Phase](../../execution/phases/00-foundation.md), [ADR-0013](0013-project-layer-structure.md)

## Context

기존 정적 대시보드는 작업 상태, 차단 사유, AI Readiness와 ROI 개선안을 보여주지만 사용자가 다음에 해야 할 일을 직접 해석해야 한다. 저장소의 이중 승인 계약을 유지한 채, 프로젝트 상태를 판단하는 하나의 읽기 전용 진입점이 필요하다.

## Decision

- 대시보드는 작업 인덱스와 readiness 보고서에서 생성하는 정적 HTML 구조를 유지한다.
- 상단에는 기준 시각·기준 커밋, 현재 상태와 단일 다음 행동을 표시한다. 다음 행동은 실행 경로를 우선해 `기획 인터뷰`, `RADIO 개발 인터뷰`, `개발 루프 진행 중`, `blocked 결정 해소`처럼 현재 계약에서 필요한 안내를 말한다.
- 추천마다 직접 선행 조건, 차단 사유와 관련 task·문서를 표시한다. 대안 후보와 phase 진행 요약을 함께 제공하고 상세 의존성 경로는 필요할 때만 펼친다.
- 대시보드는 advisory다. task 승인, 상태 전환, 구현 실행을 수행하거나 유도하는 제어 기능을 만들지 않는다. 실행 큐의 진행은 개발 루프가 소유하고 대시보드는 그 결과를 읽기만 한다.
- task가 `done`, `blocked`, `skipped` 최종 상태로 전환되거나 phase 경계 상태가 바뀌면 관련 실행 경로는 readiness 보고서와 대시보드를 재생성한다.
- 생성물은 기준 시각·기준 커밋을 표시한다. 원본이 누락되거나 생성물이 현재 상태보다 오래되면 샘플 또는 추정 값을 보이지 않고 누락·오래됨 상태를 표시한다.

## Consequences

- 사용자는 대시보드 한 곳에서 현재 실행 상태, 다음 행동의 이유, 직접 차단 조건과 전체 phase 진행을 판단할 수 있다.
- 추천은 workflow 상태와 의존성에 근거하므로 ROI가 높은 임의의 개선안을 현재 실행 작업으로 오인하지 않는다.
- task·phase 종료 처리, readiness 생성, dashboard 생성의 순서와 실패 처리는 구현 task의 RADIO에서 정하고 회귀 검증한다.
- 대시보드가 잘못된 상태를 조작할 수 없으므로 승인과 실행의 기존 안전 경계는 유지된다.

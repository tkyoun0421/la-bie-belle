# ADR-0004: 출퇴근을 서버 시각 append-only 사건으로 저장

- 상태: Accepted
- 날짜: 2026-07-23

## Context

출퇴근 시간은 누구도 수정할 수 없는 절대 기록이어야 한다. GPS가 우선이지만 실내 정확도나 권한 문제로 실패할 수 있어 주간 QR 대체 수단이 필요하다. 팀장은 출근·결근을 현장에서 확인할 수 있어야 한다.

## Decision

- 출근과 퇴근은 `attendance_events`에 서버 `now()`로 INSERT한다.
- 클라이언트가 보낸 시각은 저장하지 않는다.
- 원본 사건에 GPS 거리·정확도 또는 QR 키 버전과 인증 방식을 기록한다.
- 원본 테이블의 UPDATE와 DELETE를 모든 역할에 금지한다.
- 사용자·스케줄·사건 유형 고유 제약과 멱등성 키로 중복을 막는다.
- 팀장의 현장 확인과 결근 처리는 `attendance_attestations`에 별도 append-only 사건으로 저장한다.
- 출결 상태는 원본과 확인 사건을 합성한 projection으로 조회한다.
- GPS 기본 반경과 정확도 한도는 각각 100m이며 실패하면 수요일 갱신 QR을 사용한다.

## Consequences

- 잘못 누른 출퇴근도 원본을 고칠 수 없으며 후속 확인 사건으로만 설명할 수 있다.
- 감사 가능성이 높아지고 관리자 임의 수정 위험이 사라진다.
- 조회 시 여러 사건을 합성해야 하므로 view 또는 projection이 필요하다.
- GPS·QR은 완벽한 부정 방지 수단이 아니며 현장 팀장 확인이 보완책이다.

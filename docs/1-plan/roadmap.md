# 로드맵

큰 순서가 산다. 어떤 기능 묶음이 어떤 차례로 어떤 릴리스가 되는가다. task 하나의 순서는 `../backlog.md`의 「다음」이 담고, 여기는 묶음 단위만 담는다.

아직 백지다. 시나리오와 지표가 서면 그 위에서 정한다.

## 틀

| 릴리스 | 담는 것 | 빼는 것 | 판정 기준 |
| ------ | ------- | ------- | --------- |

- **담는 것** — 이 릴리스에 들어가는 기능 묶음, 이름으로
- **빼는 것** — 다음으로 미루는 것, 이유 한 줄
- **판정 기준** — 이 릴리스를 내보내도 된다고 판정하는 조건

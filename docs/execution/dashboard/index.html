  • F-01테스트

    app-build 검증이 서버 경계를 판별하지 못했다

    저장소에 "use client"가 하나도 없어 사용자 코드가 전부 서버 컴포넌트인 상태에서는 클라이언트 번들에 서버 표식이 없는 것이 당연하다. server-only 패키지를 제거해도 같은 결과가 나오므로 이 검사는 경계 동작을 입증하지 못했고, RADIO가 요구한 '클라이언트에서 import하면 빌드가 실패한다'는 절차도 없었다. 또한 명령으로 등록되지 않아 회귀에서 재현할 수단이 없었다. 임시 Client Component로 실패 경로를 실측해(Turbopack이 server-only 오류로 빌드 중단) 증거를 남기고, pnpm check:app-build로 표식 검사를 고정해 수정 반영 완료.

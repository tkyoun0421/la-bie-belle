행 앵커 그림 — 라운드 23 확정

기준은 라운드 7 어법이다 — 다색 그라디언트 · 위가 밝고 아래가 어두운 입체 · 배경 블록 없이 그림 자체로 선다. 아래 셋이 확정본이고, 비교하던 회백·사각 배경 벌은 걷었다. 색은 셋 중 둘이 이미 쓰던 그라디언트고 새로 는 것은 보라 하나다.

지난주 — 초록 지폐 + ₩. 애플 💵의 짜임이다 — 초록 그라디언트 지폐, 흰 안쪽 테, 가운데 연초록 원에 진초록 ₩. 손 든 사람의 셔츠와 같은 초록을 그대로 쓴다. 앞서 있던 동전 더미는 새긴 통화 기호가 ¥로 읽혀 걷었다(원화는 ₩).

8월 — 다색 막대 셋. 애플 📊의 짜임으로 호박·파랑·초록 막대가 그림 자체로 선다. 셋 다 이미 쓰는 그라디언트라 새 색이 없다. 앞서 있던 파랑 사각 배경은 「배경 블록 없이 그림 자체로 선다」 위반이고 출근 버튼의 파랑과도 경쟁했다.

누적 — 보라 오름 꺾은선 + 화살촉. 애플 📈의 방향을 순환 화살표(🔄)와 같은 선 굵기 4.2로 그렸다 — 종이 없이 선 자체로 선다. 보라(#b18cff → #6a3bd8)는 이 그림이 들여온 고정색이다. 애플의 빨간 선은 「빨강은 진짜 오류에만」 규칙에 걸려 못 쓴다.

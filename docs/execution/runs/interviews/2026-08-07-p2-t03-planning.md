- 신청 UX 상세(로컬 선택·하단 변경 개수·확인창 없는 철회·저장 실패 시 로컬 보존·스낵바 문구) — WORKER-FLOWS 근무 신청 절이 소유.
- 달력 셀 상태·규격 — DESIGN COMPONENTS가 소유.
- 원자성(부분 성공 없음)과 다른 사용자 신청 비노출 — phase 인수 조건이 소유.

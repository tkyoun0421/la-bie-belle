### 다시 열지 않은 것

- **CI가 실행할 검증 목록** — phase 문서 109행이 "위 전부 + Playwright E2E + type-aware 린트 + `pnpm gate:all`"로 이미 정의(`pnpm verify`가 그 정본). 재결정 없음.
- **문서 검사 4종의 필요성** — phase 인수 조건이 이미 봉인(순환·제목 일치·spec_refs 유효성·내부 링크). 인터뷰는 현행 `gate:index`와의 중복 제거만 확인했다: 파싱·schema·의존 존재·진행 task 최대 1은 이미 기계 강제라 공백 4종만 신설 대상이다.

### 조정자가 판단해 기록한 것

- **CI 플랫폼과 트리거**: GitHub Actions(저장소가 GitHub), push(main)와 pull_request에서 실행. 다른 CI 후보가 없어 질문으로 올리지 않았다.
- **CI 부팅 env**: `.env.example`의 공개 로컬 데모 값 복사(P0-T04 handoff가 "공개, 비밀 아님"으로 확정). GitHub secrets는 이번 범위에서 불필요하다.
- **신규 검사의 게이트 승격 없음**: 신설 검사(순환·제목·spec_refs·링크)는 CI·verify에서 실행하되 pre-commit 게이트 4종 체계는 바꾸지 않는다. 커밋 시간 증가를 피하고, 문서 드리프트는 CI 차단으로 충분하다.

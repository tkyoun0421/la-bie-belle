### 다시 열지 않은 것

- 상태 5종과 확정 후 revision 증가 — ADR-0003 소유.
- 마감 자동 처리 시각(지정 날짜 23:59:59 Asia/Seoul) — PRD 184행 소유. 자동 마감 실행은 P2-T04.
- 마감 전 자유 신청·취소(재신청 포함) — PRD 189행 소유.
- 신청 자격(활성 근무자, 관리자 동일 흐름) — 권한 매트릭스와 P2-T03이 소유.

### 조정자가 판단해 기록한 것

- 재오픈 시 기존 applied 신청은 유지된다 — 신청은 독립 엔티티이고 마감은 접수 차단만 담당한다는 구조적 귀결이라 별도 질문으로 올리지 않았다. phase 문서에 명시했다.

### 비목표

### 미결 사항

- 신청 이력의 저장 모델(단일 행 상태 전이 + 감사 vs 이력 행 누적)은 설계(RADIO)가 정한다.
- 마감 시각의 저장 형태(date + KST 파생 vs timestamptz)와 KST 경계 계산의 소유 위치는 설계가 정한다 — 메모리의 타임존 경계 규칙(DEV-TIME 후보) 승격 재론을 설계 인터뷰에 포함한다.
- RLS(다른 사용자 신청 비노출)의 스키마 수준 구현은 설계가 정한다.
- `check_ids`(`schedule-migration`, `recruitment-state-transition`)는 index에 등록돼 있다. 설계에서 세분화가 필요하면 재검토한다.

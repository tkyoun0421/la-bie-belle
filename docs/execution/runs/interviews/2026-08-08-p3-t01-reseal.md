### 배경

개발 커밋 892d06f의 교차 검증(opus·codex)에서 F-01(high, security)이 확정됐다 — 새
마이그레이션이 `schedules`에 추가한 예정 출퇴근 컬럼이 기존 활성 근무자 SELECT 정책(P2 봉인)을
통해 근무자 전원에게 노출된다. RADIO는 "예정 시각 조회는 admin 전용"을 봉인했지만 이 요구는
현재 구조로 지킬 방법이 없다: RLS는 행 단위 제어라 근무자에게 보이는 행에서 특정 컬럼만 가릴
수 없고, admin과 근무자가 같은 DB role(authenticated)이라 컬럼 권한으로도 구분되지 않는다.
봉인 규칙끼리의 충돌이라 조용히 조정하지 않고 사용자 결정을 받았다.

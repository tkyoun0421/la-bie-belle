### 확정된 사실

- **기획 승인(user, 2026-08-07)**. 사용자는 사용량 한도로 Claude Code가 멈춘 뒤 리셋 시 같은 작업을 자동 재개하기를 원한다.
- 실행 대상은 두 승인(product·RADIO)을 마친 `planned` task로 한정한다. 승인 게이트를 자동으로 열거나 새 결정을 확정하지 않는다.
- `in_progress`는 저장소 전체에서 하나만 유지하고, 재개 시 중복 worker를 만들지 않는다.
- 추가 사용량 결제·업그레이드·자격 증명 변경은 자동으로 하지 않고 정규 한도 리셋을 기다린다.
- Mac 잠자기 방지와 재부팅·로그인 복구는 이번 task 범위가 아니다. 사용자가 이미 잠자기를 막아둔 실행 환경을 전제로 한다.
- 인증 실패·반복 복구 실패·critical 검증 실패·새 결정 필요는 자동 재시도하지 않고 안전 중단한다.
- `index.jsonl`, RADIO, handoff와 실행 증거가 대화 transcript보다 우선하는 복구 기준이다.

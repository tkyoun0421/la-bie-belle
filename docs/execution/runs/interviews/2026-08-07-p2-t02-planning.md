### 다시 열지 않은 것

- 원자성(부분 성공 없는 전체 롤백)과 충돌 날짜 안내 — phase 문서가 소유.
- 생성 시 예식·출퇴근 상세 미요구, 월 8개 이상 — phase 문서 인수 조건이 소유.
- 관리자 전용 권한 — ARCHITECTURE 매트릭스가 소유.
- 생성 직후 상태 OPEN, 근무일·마감일만으로 생성 — ADR-0003이 소유.
- 활성 중복의 정의(CANCELLED 제외)와 날짜 규칙 — P2-T01 기획이 소유.

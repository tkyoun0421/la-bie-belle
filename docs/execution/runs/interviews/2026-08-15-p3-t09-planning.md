# P3-T09 기획 인터뷰 handoff

## 확인된 사실 (사용자 답변·요약본 승인)

- **revision은 저장 1회당 +1.** 한 저장으로 묶인 변경 여러 건은 revision 하나. 감사도 묶음 단위, P4 알림도 묶음당 1건으로 이어붙일 기반.
- **확정 후 추가 배정자·교육생은 추가 시점 즉시 스냅샷.** 확정 스케줄의 모든 배정 행은 항상 스냅샷을 가진다는 불변 유지. 시급 미설정자는 추가 자체를 차단.
- **교육 칩 숨김 편입.** 2026-08-14 제품 결정(다른 포지션 정식 배정자에게 교육생 선택지 미표시)의 구현을 이 task가 맡는다.
- **확정 후 취소는 확인 다이얼로그만, 사유 미입력.** 영향 인원 수 표시, 행위자·시각·전후 상태만 감사, 배정·스냅샷 보존, 되살리는 전이 없음.
- **구조 깨는 변경 차단.** 마지막 예식 삭제·예정 시각 해제·시급 미설정자 추가 거부. 미달은 경고만.
- **근무자 화면은 revision 기반 최소 표시만.** 전후 값 diff는 P4 알림 본문 몫.

## 해석·가정 (요약본에 포함해 승인됨)

- 변경 UI는 기존 관리자 준비 화면 재사용 — 확정 후 읽기 전용 전환 해제. 별도 화면 없음.
- 취소된 스케줄은 근무자 캘린더에서 기존 동작대로 사라진다. P4 알림 전까지 근무자 인지 수단은 revision 표시뿐 — 공백을 사용자가 인지했다.
- CANCELLED에서 되살리는 전이 없음. 근무자발 취소·교대 요청은 P4.

## 코드 대조에서 정해진 것 (P3-T06 기획·개발에서 확인된 사실 승계)

# P5. GPS·QR 출퇴근과 팀장 출결

## 목표

수정 불가능한 출퇴근 원본을 GPS 우선·QR 대체 방식으로 기록하고 당일 팀장이 지각·결근을 확인한다.

## 진입 조건

- P4 완료.
- 관련 spec: [PRD](../../product/PRD.md) `INV-ATT-01`, `AC-07`, `AC-08`, [Domain](../../product/DOMAIN.md) `DOMAIN:ATTENDANCE`, [ADR-0004](../../standards/adr/0004-immutable-attendance-events.md).

## 작업

### P5-T01. 장소와 주간 QR 설정

- 단일 venue의 좌표, GPS 반경, 정확도 한도 관리 화면을 만든다.
- 기본값을 반경 100m, 정확도 100m로 적용한다.
- Asia/Seoul 수요일을 시작으로 주간 QR 서명을 생성·검증한다.
- 관리자와 당일 팀장이 현장 QR을 표시할 수 있게 한다.

인수 조건:

- 이전 주 QR과 위조된 QR이 거절된다.
- 비밀키나 서명 원문이 일반 API에 노출되지 않는다.

### P5-T02. append-only 출퇴근 스키마

- attendance_events와 attendance_attestations를 만든다.
- UPDATE/DELETE 권한을 모든 애플리케이션 역할에서 제거하고 불변성 trigger로 서버 전용 경로도 차단한다.
- check-in/out 고유 제약과 멱등성 키를 구현한다.
- 서버 시각과 인증 증거 필드를 정의한다.

인수 조건:

- 사용자·관리자·서버 command의 직접 수정·삭제 시도가 모두 실패한다.
- 애플리케이션도 수정 API를 제공하지 않는다.

### P5-T03. 출근·퇴근 command

- 확정 assignment와 현재 서버 시각을 검사한다.
- 출근은 예정 출근 2시간 전부터 허용한다.
- 퇴근은 예정 퇴근 1시간 전부터 허용한다.
- QR 또는 GPS 증거를 검증한 후 서버 `now()`로 기록한다.
- 반복 탭과 네트워크 재시도에 같은 결과를 반환한다.

인수 조건:

- 허용 시간 전, 미배정 사용자, 중복 사건을 차단한다.
- 클라이언트가 조작한 시각을 무시한다.

### P5-T04. GPS 우선·QR 대체 모바일 흐름

- 정밀 위치 권한을 요청하고 거리·accuracy를 서버에 전달한다.
- 성공하면 출퇴근 결과와 서버 시각을 표시한다.
- 권한 거부, 낮은 정확도, 반경 밖, timeout이면 QR 스캔으로 안내한다.
- QR 스캔 후 같은 command를 수행한다.

인수 조건:

- GPS 실패가 출퇴근 전체 실패로 끝나지 않고 QR 경로를 제공한다.
- 위치와 카메라 권한 오류를 사용자가 이해할 수 있다.

### P5-T05. 지각과 출결 projection

- 예정 출근을 1분이라도 넘기면 자동 `LATE`로 계산한다.
- 출근, 퇴근, 누락, 결근을 projection/view로 제공한다.
- 예정 퇴근 이후 퇴근 원본이 없으면 `MISSING_CHECK_OUT`을 표시한다.
- 원본과 계산 결과를 구분해 표시한다.

인수 조건:

- 예정 시각과 정확히 같은 출근은 정상, 다음 분부터 지각이다.
- projection 재생성 결과가 결정적이다.

### P5-T06. 당일 팀장 출결 화면

- 확정 팀장에게 해당 날짜 전체 배정자의 출결을 보여준다.
- 팀장이 타인의 현장 출근 확인과 결근 사건을 추가한다.
- 팀장은 자신의 출결 확인을 추가할 수 없다.
- 관리자는 팀장 본인을 포함해 전체를 확인한다.

인수 조건:

- 다른 날짜 팀장이나 일반 근무자는 출결 목록을 볼 수 없다.
- 결근 처리는 배정과 원본을 삭제하지 않는다.

### P5-T07. 출퇴근 누락 알림

- 예정 출근 시각에 미인증이면 본인과 당일 팀장에게 알린다.
- 출근 전 사전 알림은 만들지 않는다.
- 예정 퇴근 시각에 미인증이면 본인과 팀장에게 알린다.
- 해당 날짜에 배정되지 않은 관리자는 자동 수신하지 않는다.

인수 조건:

- 늦게 출근한 사용자는 지각으로 남고 불필요한 반복 알림을 받지 않는다.
- Cron 재실행으로 누락 알림이 중복되지 않는다.

### P5-T08. 실제 기기와 보안 검증

- Android, iPhone 홈 화면 PWA에서 위치·카메라·푸시 조합을 검증한다.
- 거리 경계, accuracy 경계, 주차 변경, 시계 조작, 중복 탭을 테스트한다.
- 출퇴근 원본 수정·삭제와 팀장 권한 우회를 회귀 테스트한다.

인수 조건:

- 지원 기기 체크리스트와 알려진 제한을 운영 문서에 기록한다.
- PRD의 출퇴근 인수 조건이 E2E 또는 통합 테스트로 연결된다.

## 종료 조건

- 현장에서 GPS 실패 시에도 QR로 출퇴근할 수 있다.
- 관리자도 출퇴근 원본을 수정할 수 없다.
- 팀장이 당일 지각·결근을 앱에서 확인한다.

## 제외

- 실제 근무시간 정정.
- GPS 위변조 완전 차단.
- 리허설 출퇴근 인증.

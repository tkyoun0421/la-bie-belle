# ADR-0006: 급여는 스냅샷 기반 예상치로만 제공

- 상태: Accepted
- 날짜: 2026-07-23

## Context

제품은 시급 기반 예상 금액이 필요하지만 실제 급여 지급·정산·명세서는 범위 밖이다. 개인 시급 변경으로 과거 표시 금액이 바뀌면 신뢰가 떨어진다.

## Decision

- 일반 근무는 확정 시점 개인 시급을 assignment에 스냅샷한다.
- 리허설은 기록 생성 시점 개인 시급을 스냅샷한다.
- 최초 540분은 기본 시급, 초과분은 1.5배를 적용한다.
- 출근부터 퇴근까지 전부 유급이며 분 단위 비례 계산한다.
- 일반 근무는 예정 출퇴근 시간만 사용하고 실제 출퇴근 시각은 사용하지 않는다.
- 결근 처리된 일반 근무의 표시 금액은 0원이다.
- UI와 문서에서 항상 `예상 급여` 또는 `급여 참고`로 표현한다.
- 지급 상태, 공제, 세금, 명세서 데이터를 만들지 않는다.

## Consequences

- 과거 예상치가 개인 시급 변경으로 흔들리지 않는다.
- 실제 임금 계산과 차이가 있을 수 있음을 사용자에게 명확히 알려야 한다.
- 확정 후 시급을 바꾸려면 스케줄 revision에서 명시적으로 스냅샷을 갱신해야 한다.
- 급여 정산 요구가 생기면 별도 PRD와 ADR이 필요하다.

# ADR-0010: 휴면과 자동 계정 생명주기

- 상태: Accepted
- 날짜: 2026-07-24
- 관련 결정: [ADR-0002](0002-authorization-boundaries.md), [ADR-0007](0007-offboarding-and-history-recovery.md)

## Context

기존 계정 모델의 `일시 정지`는 사용 목적, 기간과 배정 연쇄 처리가 정해져 있지 않았다. 실제 운영은 익월 근무 신청이 중심이므로 장기간 신청하지 않는 계정을 휴면 처리하고, 더 오래 활동하지 않은 계정은 기존 탈퇴·복구 정책으로 정리할 필요가 있다. 동시에 관리자 직접 배정, 오래된 화면, 동시 요청과 외부 개인정보 정리 실패가 계정과 스케줄을 모순 상태로 만들지 않아야 한다.

## Decision

- `일시 정지`를 제거하고 본인과 관리자가 해제할 수 있는 `휴면` 상태를 사용한다.
- 정상 저장된 출근 신청, 최초 활성 승인 또는 재활성화의 최신 서버 시각을 인정 활동 시각으로 사용한다. 취소된 정상 신청은 인정하고 실패·중복 신청과 로그인, 관리자 수동 휴면은 인정하지 않는다.
- 인정 활동 후 Asia/Seoul 달력 기준 3개월이면 휴면, 1년이면 자동 탈퇴 대상이 된다. 같은 일자가 없는 월은 월말을 사용한다.
- 활성 신청 또는 진행 중·미래 활성 배정이 있으면 자동·수동 휴면과 자동 탈퇴를 차단한다. 과거 완료·취소 배정은 차단하지 않는다.
- 본인과 관리자는 휴면 계정을 재활성화할 수 있다. 재활성화는 두 기한을 모두 초기화하며, 사유 없이 행위자·시각·변경 전후 상태를 감사 기록에 남긴다.
- 자동 탈퇴 사전 알림은 발송하지 않고 휴면 화면에 자동 탈퇴 예정일을 표시한다.
- 자동 탈퇴는 ADR-0007의 일반 탈퇴와 같은 개인정보 삭제, 3년 vault와 과거 이력 보존을 적용한다.
- 한 번도 활성 승인되지 않은 승인 대기·거절 계정은 각각 가입·거절 후 3개월에 vault 없이 완전 삭제하고 승인 감사 기록만 익명화한다. 로그인은 기한을 연장하지 않는다.
- 자진 탈퇴는 즉시 완료한다. 활성 신청은 자동 취소하고 대기 변경 요청은 무효화한다. 진행 중·미래 확정 배정은 `change_required`로 표시해 필요 인원에서 제외하지만 스케줄 확정 상태는 유지한다.
- 대체 근무자를 지정하면 같은 배정의 근무자를 교체하고 `change_required`를 해제한다. 별도 대체 상태는 만들지 않고 변경 전후와 처리자를 감사 기록에 남긴다.
- 상태 전환은 계정과 관련 차단 자료를 잠그는 트랜잭션으로 처리하며 먼저 완료된 작업만 유효하다.
- 한국 시간 기준 매일 새벽 멱등 작업으로 자동 전환한다. 최초 적용 때 기존 계정의 기준 시각은 기존 값과 정책 적용일 중 더 늦은 값으로 정한다.
- 외부 연결 정리가 실패해도 탈퇴를 되돌리지 않는다. 실패 작업은 멱등 재시도하고 장기 실패를 관리자에게 노출한다.

## Consequences

- 휴면은 징계나 근무 불가 의미가 아니라 장기 미신청 계정의 가역적 접근 제한이다.
- 진행 중·미래 신청과 배정이 있는 계정은 휴면·자동 탈퇴되지 않으므로 스케줄과 계정 상태의 모순을 예방한다.
- 자진 탈퇴는 즉시성을 유지하는 대신 배정 교체와 진행 중 출결 예외를 운영자가 처리해야 한다.
- 탈퇴 후 체크아웃 처리와 출결 projection 우선순위는 이 ADR에서 정하지 않고 출퇴근 결정으로 남긴다.
- 자동 처리의 시간 경계, 동시성, 초기 유예, 부분 실패와 감사 기록을 통합 테스트해야 한다.

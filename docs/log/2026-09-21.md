# 2026-09-21 — Expo 골격을 세우고 웹 전제를 걷어낸다

PR #380 하나(커밋 서른넷, 파일 226개)로 ADR-011(웹 PWA → Expo 네이티브)과 ADR-012(브랜드 파랑, 헐거운 밀도) 두 결정을 설계 층부터 저장소까지 전파했다. 앱 골격이 섰고 테스트 러너가 vitest에서 Jest로 옮겨졌다.

## 설계 전파

디자인 시스템 여섯, `system/` 넷, modules design 셋, 화면 문서, `1-plan`·`4-test`·`5-deploy`·`CLAUDE.md`를 네이티브 전제로 다시 썼다. 시안 열여섯을 파랑 팔레트로 옮기고 그림자를 걷었다.

전파 중 정본 충돌 셋이 드러나 결정을 받아 닫았다. 면의 안쪽 여백이 `spacing-shape.md`만 20px에 남아 화면 문서 열셋과 갈려 있던 것을 24px로 묶었다. 눈금 밖 여백 열셋을 이웃 눈금으로 당겼다. 대표 숫자가 색으로 말하게 했다 — 진한 색면 한 장을 주요 버튼이 이미 쓰고 있어 면이 한 장 더 들던 자리였다.

ListRow 조항 하나는 충돌이 아니라 한 조항에 두 종류가 눌려 있던 자리였다. 오른쪽 값을 「그 줄의 데이터면 `fg.neutral`, 화살표 달린 문의 현재 상태면 `fg.neutral-muted`」로 갈랐고, 가르는 질문은 「이 값을 보려고 이 화면에 왔는가」다. 시안은 한 장도 안 고쳤다 — 이미 다 그 규칙대로 서 있었다.

## 앱 골격

Expo SDK 57 + Expo Router + NativeWind v5로 라우트 스물둘과 탭 넷을 세웠다. NativeWind는 v5 RC를 딛는다 — stable v4는 Tailwind 3을 요구하는데 디자인 정본이 Tailwind 4 위에 서 있어서다. 내려갔다 올라오면 생성기와 대비 검증과 lint 테스트를 두 번 고치게 된다.

토큰 파이프라인을 `@tailwindcss/postcss` → `react-native-css/compiler`로 실제로 태워 확인했다. 네이티브 rem은 16(기본값 14에서 올라갔다), `p-4`가 16, `text-base`가 17, 브랜드가 라이트 `#2f5cf6`·다크 `#628dfc`다. `tests/lint/native-compile-values.test.ts`가 이 값을 못박는다. 걱정하던 OKLCH는 컴파일러가 빌드 때 hex로 바꿔 생성기가 따로 변환할 필요가 없었다. 다크 갈래는 미디어 쿼리 하나로 줄었다 — 네이티브 컴파일러가 `:root`에 속성이 붙은 선택자를 거부해서 「밝게·어둡게」를 고르는 길이 선택자가 아니라 `Appearance.setColorScheme()`이 됐다.

## 웹 걷어내기

웹 전제 위에만 서던 파일 열여섯과 빈 디렉터리 다섯을 지웠다. `no-get-session` 테스트도 같이 뺐다 — 「서버가 쿠키를 그대로 믿지 않는다」는 규칙인데 앱에는 서버도 쿠키도 없다.

## 러너 이사

vitest에서 Jest로 옮겼다. 481개가 러너를 바꿔도 같은 수, 같은 초록불로 남는 것이 판정 근거다. `.mts`가 네 겹으로 막혔고 넷 다 설정으로 풀었다 — `jest-expo`의 `babel-jest` 옵션 덮어쓰기(우리에겐 `babel.config.js`가 없어 복구할 것이 없었다), `babel-preset-expo`가 `.ts`·`.tsx` 문자 그대로만 보는 판정, 최상위 `await`이 CJS로 표현이 안 되는 것, `import.meta`가 Metro 런타임이 채우는 자리라 Jest에는 그 런타임이 없는 것. 러너를 CJS와 ESM으로 쪼갤 이유(`jest.mock()`이 ESM에서 안 먹는 것)를 쓰는 테스트가 하나도 없어 전부 ESM으로 갔다.

## 훅과 CI

e2e 훅이 양쪽으로 틀려 있었다 — Next 파일 이름을 물고 있어서 `src/screens/` 아래는 무조건 막으면서 정작 Expo Router 라우트는 하나도 안 봤다. 이름을 고치고, e2e 러너를 고르기 전까지는 아무것도 요구하지 않게 했다. 요구를 채울 방법이 없는 게이트는 게이트가 아니라 벽이라는 것이 그 근거다. `e2e-runner` 행이 `backlog.md`에 이미 서 있고, 그것이 닫혀야 게이트가 다시 문다.

CI에서 앱 빌드와 e2e 단계를 뺐다 — 부르는 스크립트가 웹과 같이 사라져 이대로면 빨간불이었다. 빌드는 EAS 설정과, e2e는 러너 선택과 같이 돌아온다.

## 미실행 범위

`pnpm dev`는 대화형이라 안 돌렸다. Expo Go로 실기기에서 뜨는 것은 아직 확인 못 했다 — `expo-scaffold` plan의 AC-01·05·07·08·09가 미실행으로 남는다. 다음 세션의 첫 수가 이것이다.

## 남은 것

`expo-scaffold`는 `active`로 남는다. 골격 뼈대와 토큰 파이프라인과 러너 이사가 섰고, 남은 것은 서체 넷·세션·딥링크·진입 판정이다. `sian-native-pass`도 `active`로 남는다 — 시안 열여섯이 아티팩트로 올라갔고 사람의 승인을 기다린다.

# 6-maintain — 운영

아직 백지다. 운영 중인 배포가 없다. 첫 출시 준비 task가 배포 문서와 같이 채운다 — 운영이 시작된 뒤가 아니다. 첫 운영 전에 서야 하는 최소는 장애를 확인하는 자리, 대응 담당, 복구 뒤 확인 방법이다. 지표는 측정을 만들기 전에 집계 기준(분모·기간·수집 대상)이 [metrics.md](../1-plan/metrics.md)에 선다.

다룰 것: 모니터링, 인시던트 절차, 운영 지표.

미뤄둔 것: CI eval, 알림이 에이전트를 깨워 스스로 intent를 쓰는 자율 유지보수. 근거는 ADR-005의 범위 밖 절에 있다.

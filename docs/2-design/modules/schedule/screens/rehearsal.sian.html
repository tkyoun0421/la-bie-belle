라비에벨 · 페이지 디자인

리허설 화면 시안

화면이 달력이다. 날을 눌러 그날 시트를 열고 거기서 넣는다 — 근무표와 같은 문법이고 하단 고정 버튼이 없다. 넣는 시트에 날짜 칸이 없다. 갈래(시각·건수)는 달력에서 고른 날에 이미 정해져 있다.

01 / 달력

날을 누르면 그날 시트가 열린다

정상, 리허설이 없는 달, 관리자, 읽는 중, 못 읽음 다섯이다. 모든 칸이 눌린다 — 지난 날도 안 연 날 개념도 없다. 바닥 단은 건수가 아니라 시간이다.

02 / 날 시트

날짜는 이미 골랐다

빈 날, 든 날(줄 하나·줄 둘 이상), 건수 갈래로 이미 넣은 날, 관리자(든 날·빈 날) 여섯이다.

03 / 넣는 시트

날짜 칸이 없다

날 시트 위에 한 겹 더 선다. 시각 갈래, 건수 갈래, 겹침, 갈래 어긋남, 저장 실패 다섯이다. 라디오도 탭도 없다 — 이미 정해진 갈래로 바로 칸이 열린다.

04 / 고치는 시트

값이 든 채로 열린다

넣는 시트와 같은 칸이 값과 함께 열리고, 아래에 「지우기」 한 줄이 더 선다. 날짜를 못 고친다.

05 / 지우기 확인

한 번 더 묻는다

고치는 시트 위에 뜨는 가운데 Dialog다. 지운 값을 되돌리는 길이 없고 급여가 바로 따라 줄어서다.

06 / 모션 — 넣은 뒤·지운 뒤

줄이 오르고, 줄이 접힌다

아래 목업의 점선 버튼 둘을 눌러본다. 「데모: 새 줄 추가」는 넣은 뒤 날 시트에 새 줄이 --duration-base(180ms)로 오르는 것을, 「데모: 방금 줄 지우기」는 지운 줄이 --duration-fast(125ms)로 접혀 사라지는 것을 보여준다. 이 둘은 시안 전용 보조 버튼이고 실제 화면에는 없다 — 진짜 화면에서는 넣는 시트의 「넣기」와 고치는 시트의 「지우기 → 지우기 확인」이 같은 결과를 일으킨다.

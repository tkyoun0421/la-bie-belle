# 2-design — 설계

설계의 전체 그림이 이 파일이다. 갈래마다 정본은 하나다.

- `domain/` — 개념 설계. 용어와 규칙의 정본
- `architecture/` — 구조 설계. `data-model/`(테이블과 관계), `api/`(경계와 권한), `runtime/`(캐시·시각·경쟁·로딩), `flows/`(화면 간 흐름). 관심사가 폴더고 도메인이 파일이다
- `design-system/` — 시각 설계
- `adr/` — 되돌리기 어려운 결정과 그 근거. 어느 단계의 결정이든 전부 이 한 곳에 쌓는다
- `spec/` — 기능별 명세와 완료 조건. 프론트매터 `status`가 태관의 승인 마크고, 승인 없이 구현으로 못 간다

기능은 spec이 승인돼야 `3-build/`로 넘어간다. 근거는 ADR-005에 있다.

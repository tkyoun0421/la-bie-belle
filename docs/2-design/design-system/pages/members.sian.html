라비에벨 · 페이지 디자인 07

직원 시안

관리자 홈의 「직원」 줄이 여는 화면이다. 이미 승인된 사람만 다룬다 — 가입 승인·거절·차단은 가입 대기 화면 몫이다. 여기서 하는 일은 이름 고치기, 관리자로 올리고 내리기, 퇴사 처리 셋이고 관리자 화면이라 탭 바가 없다. 오른쪽 위 토글이 페이지 전체를 라이트와 다크로 뒤집는다.

01 / 목록

재직자와 퇴사 구획이 한 화면에 있다

재직자는 이름 가나다순이고 관리자를 위로 올리지 않는다. 퇴사한 사람은 같은 화면 아래, 가는 선 너머에 퇴사한 날이 늦은 순으로 선다. 한 명도 없으면 구획이 통째로 없다.

02 / 사람 시트

값 넷, 이름 고치기, 역할 버튼, 더보기

줄을 누르면 아래에서 올라온다. 시급은 값과 「기본」 배지만 있고 화살표가 없다 — 고치는 자리가 아니라서다. 연락처를 누르면 전화가 걸린다는 뜻으로 수화기가 선다.

03 / 퇴사 확인

배정이 남았으면 막고, 없으면 묻는다

더보기의 「퇴사 처리」를 누르면 뜬다. 시트가 아니라 화면 가운데 Dialog다. 배정이 남아 있으면 저절로 안 빼주고 근무표로 보낸다.

04 / 관리자로 올리기 확인

올리는 것도 내리는 것도 확인을 한 번 묻는다

올리는 것은 그 사람이 근무표와 급여와 남의 프로필을 전부 보게 되는 일이라 Dialog 하나로 묻는다. 내리기도 같은 모양이라 여기는 올리기만 그렸다.

05 / 퇴사한 사람 시트

같은 틀, 다른 것은 셋

퇴사 구획의 줄을 누르면 올라온다. 퇴사한 날이 이름 아래에 서고, 이름 고치기와 역할 바꾸기가 없고, 더보기 자리에 「되돌리기」가 있다.

06 / 끝난 뒤

토스트 둘 — 되돌리기는 없다

이름을 고치거나 퇴사 처리를 마치면 목록으로 돌아오고 토스트가 뜬다. 관리자로 올리고 내리기, 퇴사를 되돌리기도 같은 모양의 성공 토스트를 쓴다 — 문장만 갈린다.

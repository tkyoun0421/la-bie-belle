# QR

관리자가 현장 QR을 보고 바꾸는 화면이다. 값은 [tokens.md](../tokens.md)에만 있고 여기는 토큰 이름으로만 말한다.

근무자는 홀에서 이 코드를 찍어 출근을 남긴다. 위치와 QR 둘 중 하나만 통과하면 되고, 규칙은 [domain/attendance.md](../../domain/attendance.md#두-길)에 있다.

들어오는 문은 [관리자 홈](schedule-admin.md#관리자-홈)의 「QR」 줄이다.

**코드는 고정이다.** 시간마다 도는 코드가 아니라 관리자가 바꿀 때까지 그대로다. 돌고 있다 싶으면 새로 뽑는 것이 그 값을 치르는 방식이고, [알고 남기는 구멍](../../domain/attendance.md#알고-남기는-구멍)에 근거가 있다.

---

## 짜임

세로로 쌓는다.

1. 앱바 — 뒤로와 「QR」
2. QR 그림
3. 쓰기 시작한 날
4. 버튼 셋 — 이미지 내려받기, 크게 띄우기, 새로 뽑기

**QR이 화면 가운데에 크게 선다.** 이 화면이 들고 있는 것이 그것 하나다.

**버튼 셋을 세로로 쌓는다.** [BottomCTA](../components.md#bottomcta)를 안 쓴다 — 화면의 끝에서 한 번 누르고 나가는 자리가 아니라 셋 중 무엇을 할지 고르는 자리다. 나란히 두면 셋이 같은 무게로 보이는데 「새로 뽑기」는 다른 무게다.

### QR 그림

정사각이고 흰 면에 검은 코드다. 테두리는 [Card](../components.md#card)와 같다.

**다크 모드에서도 흰 면이다.** 코드를 반전하면 카메라가 못 읽는 기기가 있다. 화면 바탕은 테마를 따르고 코드가 앉는 면만 항상 희다.

QR 아래에 쓰기 시작한 날이 한 줄이다. 지금 코드가 얼마나 오래됐는지가 새로 뽑을지 정하는 유일한 재료다.

### 이미지 내려받기

[Button](../components.md#button)의 secondary다.

인쇄해서 홀 입구에 붙이는 길이다. 관리자가 없는 날에도 근무자가 찍는다.

**내려받는 것은 인쇄용 그림이다.** 화면의 QR보다 크고 아래에 「출근 인증」 한 줄이 같이 박힌다. 종이만 보고도 무엇인지 알아야 벽에서 안 떼인다.

아이폰 사파리에서 홈 화면 앱으로 열면 파일이 사진첩으로 간다. 그 뒤는 앱 밖 일이다.

### 크게 띄우기

Button secondary다.

누르면 화면이 통째로 QR이 된다. 종이가 떨어졌거나 새로 뽑은 직후에 관리자 폰을 내미는 길이다.

| 자리 | 담는 것 |
| --- | --- |
| 바탕 | 흰 면, 화면 전체 |
| QR | 가운데, 화면 폭에서 좌우 48px을 남긴 크기 |
| 닫기 | 오른쪽 위 |

**화면이 안 꺼진다.** 이 모드에 있는 동안 화면 잠금을 막는다. 근무자 여럿이 줄 서서 찍는 자리라 중간에 꺼지면 관리자가 계속 깨워야 한다. 모드를 나가면 원래대로 돌아간다.

**밝기를 앱이 안 올린다.** 올리는 것이 읽기에는 낫지만 사람이 정한 설정을 앱이 말없이 덮는 자리가 된다.

**앱바가 없다.** 나가는 길은 오른쪽 위 닫기 하나다. 앱바를 두면 흰 면 위에 회색 띠가 얹혀 카메라가 잡는 면적이 준다.

### 새로 뽑기

Button outline이다. 셋 중 유일하게 무언가를 바꾸는 버튼인데 가장 약하게 그린다 — 자주 누를 것이 아니고, 잘못 누르면 홀에 붙은 종이가 전부 죽는다.

**destructive를 안 쓴다.** 파괴가 아니다([components.md](../components.md#button)). 새 코드를 뽑는 것이지 무언가를 지우는 것이 아니고, 빨강을 여기 쓰면 정말 멈춰야 하는 자리에서 아무도 안 멈춘다.

누르면 [확인 Dialog](#새로-뽑기-확인)가 선다.

## 새로 뽑기 확인

[components.md](../components.md#dialog와-바텀시트)의 Dialog다. 화면 가운데에 선다.

| 자리 | 문장 |
| --- | --- |
| 제목 | QR을 새로 뽑을까요? |
| 본문 | 지금 QR이 바로 끝나요. 홀에 붙여둔 종이도 갈아야 해요 |
| 왼쪽 버튼 | 닫기 |
| 오른쪽 버튼 | 새로 뽑기 |

**두 가지를 같이 말한다.** 옛 코드가 그 자리에서 죽는다는 것과, 종이를 안 갈면 다음 날 아침 모두가 실패하는 코드를 찍는다는 것이다. 뒤엣것이 관리자가 실제로 할 일이라 문장에 들어 있어야 한다.

### 뽑은 뒤

화면의 QR이 새 코드로 바뀌고 「쓰기 시작한 날」이 오늘이 된다. [토스트](../components.md#토스트)가 뜬다.

**근무자에게 푸시가 안 간다.** 미리 알아도 할 일이 없고, 알아야 할 순간은 찍었는데 안 되는 그 자리뿐이다([domain/attendance.md](../../domain/attendance.md#qr을-바꾸는-행위)). 알림 목록이 열둘에서 안 는다.

**옛 코드를 찍은 사람이 보는 것은 이 화면 밖이다.** 「이 코드는 더 쓰지 않아요」와 위치로 찍는 길이고, 자리는 [출근 인증](dashboard.md)이다.

## 색

| 자리 | 토큰 |
| --- | --- |
| 화면 바탕 | `bg.neutral` |
| 앱바 | [components.md](../components.md#앱바)의 앱바 |
| QR이 앉는 면 | 흰 면 — 테마를 안 따른다 |
| QR 테두리 | `stroke.surface` |
| 쓰기 시작한 날 | `fg.neutral-subtle` |
| 내려받기 · 크게 띄우기 | [Button](../components.md#button) secondary |
| 새로 뽑기 | [Button](../components.md#button) outline |
| 크게 띄우기 바탕 | 흰 면 |
| 크게 띄우기 닫기 | 검은 아이콘 — 흰 면 위라 테마를 안 따른다 |

**이 화면에 브랜드 색이 없다.** primary 버튼이 없다. 셋 중 어느 것도 「이 화면에 온 사람이 하려던 일」이라고 단정할 수 없어서다 — 보러 온 사람도 있고 인쇄하러 온 사람도 있다.

**QR 면이 팔레트 밖이다.** [tokens.md](../tokens.md)의 역할 토큰을 안 쓰는 자리고, 이유는 위 [QR 그림](#qr-그림)에 있다.

## 글자

| 자리 | 유틸 |
| --- | --- |
| 앱바 제목 | `text-lg font-semibold` |
| 쓰기 시작한 날 | `text-sm` |
| 버튼 라벨 | `text-base font-medium` |

날짜에 `tabular-nums`를 건다.

## 여백과 모양

| 자리 | 유틸 |
| --- | --- |
| 화면 좌우 여백 | `px-6` |
| 앱바와 QR 사이 | `mt-8` |
| QR 그림 | 화면 폭에서 좌우 여백을 뺀 정사각, `rounded-xl` |
| QR 안쪽 여백 | `p-6` — 코드 둘레의 흰 여백이다 |
| QR과 날짜 사이 | `mt-4` |
| 날짜와 첫 버튼 사이 | `mt-10` |
| 버튼 셋 사이 | `gap-3` |
| 새로 뽑기 위 | `mt-6` |

**「새로 뽑기」만 위 간격이 넓다.** 앞의 둘은 지금 코드를 쓰는 길이고 이것만 코드를 바꾼다. 간격이 그 갈림을 말한다.

QR 안쪽 여백을 넉넉히 두는 것은 코드 둘레에 흰 띠가 있어야 카메라가 경계를 잡기 때문이다.

| 쓰기 시작한 날 | 2026년 3월 2일부터 쓰고 있어요 |
| 첫째 버튼 | 이미지 내려받기 |
| 둘째 버튼 | 크게 띄우기 |
| 셋째 버튼 | 새로 뽑기 |
| 크게 띄우기 닫기 | 닫기 |
| 뽑은 뒤 토스트 | QR을 새로 뽑았어요 |
| 인쇄용 그림 안 글자 | 출근 인증 |

「쓰고 있어요」에 연도가 붙는다. 해를 넘겨 안 바꾼 코드가 있을 수 있고, 그 사실이 새로 뽑을지 정하는 재료다([writing.md](../writing.md#숫자와-단위)).

## 모션

**등장 모션이 없다.**

「크게 띄우기」는 화면이 덮인다 — `--duration-base`로 흰 면이 차오르고 나갈 때 같은 시간으로 걷힌다.

새로 뽑으면 QR 그림이 바뀐다. 갈아 끼우는 모션을 안 넣는다 — 옛 코드와 새 코드가 화면에서 섞여 보이는 순간이 생기면 어느 쪽을 인쇄해야 하는지가 흐려진다.

## 안 담은 것

**QR을 찍는 화면.** 근무자 쪽이고 [dashboard.md](dashboard.md)에 있다.

**위치로 찍는 길.** 같은 화면에 있다. 이 화면은 QR 하나만 다룬다.

**홀 좌표와 반경 고치기.** [domain/attendance.md](../../domain/attendance.md#두-길)가 DB 설정 행에 산다고 정했고 관리자가 고치는 화면은 1차에 없다.

**옛 코드로 찍은 기록.** 몇 명이 옛 코드를 찍었는지를 이 화면이 안 센다. 종이를 갈았는지 확인하는 재료가 되지만, 그것을 보려고 근무자의 실패를 모아 두는 자리를 만들지 않았다.

**시안.** 이 문서가 서고 나서 `qr.sian.html`을 그린다.

## 규칙과 부딪힌 자리

**QR 면이 테마를 안 따른다.** [tokens.md](../tokens.md)가 모든 면을 라이트와 다크 양쪽으로 정의하는데 이 자리만 항상 희다. 근거는 카메라 인식이고, 색 규칙이 아니라 기계 제약이라 예외로 남긴다.

**「크게 띄우기」가 앱바 없는 화면이다.** 이 앱에서 앱바가 없는 화면이 처음 서는 자리다. 나가는 길이 닫기 하나뿐이라 [writing.md](../writing.md#다크패턴을-쓰지-않는다)의 「뒤로가기 인터럽트」와 부딪히지 않는지 봤는데, 붙잡는 것이 아니라 나가는 길이 하나인 것이라 조항 밖이다.

**화면 잠금을 막는다.** 사람의 기기 설정을 앱이 잠깐 덮는 자리다. 모드 안에서만이고 나가면 돌아온다. 밝기를 안 건드리는 것과 갈라둔 기준은 되돌아오는지다 — 잠금은 저절로 돌아오고 밝기는 사람이 다시 맞춰야 한다.

## 아직 안 정한 것

임의로 채우지 않는다. 사람이 정하고 나서 이 절에서 뺀다.

- **인쇄용 그림의 크기와 비율.** A4에 맞추는지 정사각으로 주는지 안 정했다
- **내려받기가 막혔을 때의 문안.** 브라우저가 파일 저장을 안 열어주는 자리가 있다
- **QR을 몇 달 안 바꿨을 때 재촉할지.** 지금은 날짜만 적고 앱이 아무 말도 안 한다

# 근무자 대시보드를 만든다

디자인은 끝났고 데이터가 없다. 옛 plan 보드(지금의 `docs/backlog.md`)에서 옮겨 온 명세다 — 완료 조건 문장은 총괄이 쓴 그대로다.

## 완료 조건

- 이 task는 앞선 것들이 서기 전에는 못 연다. 대시보드가 그리는 넷(안 본 알림, 출근 인증, 이번 주 근무, 내 급여)이 전부 서버 데이터고, 그 넷을 만드는 task가 아직 보드에 없다. 무엇이 먼저 필요한지를 이름으로 적어 이 자리에 남긴다 — 근무표, 출근 인증 기록, 급여 계산, 알림이다.

## 왜

디자인 문서와 시안이 [pages/dashboard.md](../design-system/pages/dashboard.md)에 다 있는데 붙일 데이터가 없다. 순서를 안 적어두면 화면부터 만들고 가짜 데이터를 박는 길로 간다.

## 범위 밖

관리자 대시보드.

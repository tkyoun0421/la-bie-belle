# 결정 대장 항목 템플릿

[DECISIONS.md](../../../../docs/product/DECISIONS.md)에 추가하는 한 항목의 양식이다. 추가 절차는 [SKILL.md](../SKILL.md)가 소유한다.

## 양식

```markdown
- **결정의 요지 한 문장.** 조건·예외·세부 문장들. — [정본 문서 절 이름](상대/경로.md) · [둘째 정본](상대/경로.md) (YYYY-MM-DD 단계)
```

## 채우는 법

| 자리 | 규칙 |
| --- | --- |
| 요지 | 결론을 단정문으로 쓴다("~다", "~않는다", "~제공한다"). 조건으로 시작하지 않는다 |
| 세부 | 요지의 조건·예외·경계. 이월·미결은 소유 단계를 명시한다("~는 P3 기획 미결이다") |
| 정본 | 결정을 소유하는 문서를 절 이름까지 적는다("ADMIN-FLOWS 팀원 관리 절"). 여럿이면 ` · `로 연결한다 |
| 날짜·단계 | 승인일과 게이트 종류: 기획, 설계, 정합화, 검증에서 확인 |

## 작성 규칙

- 항목의 첫 볼드는 요지 한 문장뿐이다 — 볼드만 이어 읽으면 대장 전체가 스캔되는 구조를 지킨다.
- 경로는 `docs/product/` 기준 상대 경로다(대장 파일 위치 기준).
- 수치·상태 이름·task ID는 정본 표기 그대로 옮긴다.
- 대장에만 있는 사실을 만들지 않는다 — 정본에 없는 내용이면 먼저 정본에 넣을 일이다.

## 예

```markdown
- **마감 시각은 저장하지 않는다.** 마감일 + 23:59:59 KST 파생이며, 실행은 P2-T04 소유다. — [P2-T01 RADIO](../execution/radio/P2-T01-radio.md) (2026-08-07 설계)
```

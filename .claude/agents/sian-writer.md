# 시안 작성자

페이지 디자인 문서를 브라우저로 열어 볼 수 있는 HTML로 옮긴다. 디자인을 결정하지 않는다.

## 시작할 때

페이지 문서 경로 하나를 받는다. 그 문서와 [tokens.md](../../docs/2-design/design-system/tokens.md)를 전부 읽고, 형식 본보기로 기존 시안 하나(`docs/2-design/design-system/pages/*.sian.html`)의 맨 위 주석과 구조를 본다. 모션을 그릴 일이 있으면 `foundation/motion.md`도 연다.

## 무엇을 그리나

- 문서가 절로 나눈 화면들을 한 파일에 나란히 놓는다. 화면 하나가 아니라 그 화면의 **상태 전부**다 — 문서의 조건부 표와 「모든 자리」류 표에 있는 행마다 하나씩 세운다
- 모션은 CSS 애니메이션이나 최소한의 JS로 흉내 낸다. 이징·타이밍은 문서가 가리키는 토큰 값을 tokens.md에서 찾아 쓴다
- 주 타깃 폭(아이폰 세로)을 문서에서 확인하고 그 폭으로 그린다

## 지키는 것

- **문서가 정본이다.** 시안과 문서가 어긋나면 문서가 이긴다. 그 말을 파일 맨 위 주석에 박는다 — 기존 시안의 주석 형식 그대로
- 색·타이포·간격·모션 값은 tokens.md의 값과 일치시킨다. 값을 새로 지어내지 않는다
- 문서에 없는 상태나 배치를 임의로 발명하지 않는다. 문서가 비운 자리를 만나면 그리지 말고 리턴의 이슈에 적는다
- 시안 CSS는 앱으로 복사되지 않는 전제라 자유롭게 쓴다. 다만 구조를 문서의 짜임 순서와 다르게 놓지 않는다
- `.prettierignore`가 이 파일을 거르는지 확인하고 안 거르면 걸리게 한다
- 커밋하지 않는다. 파일만 남긴다

## 리턴

1. 완료 — 만든 파일 경로와 담은 화면·상태 목록
2. 미완 — 못 그린 상태와 이유
3. 명령과 결과 — 실행했다면
4. 이슈 — 문서가 비워둔 자리, 문서끼리 어긋난 자리
